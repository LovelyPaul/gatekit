```gatekit-discovery
{
  "problem": "{{해법이 섞이지 않은 문제 문장}}",
  "deadline": "{{4 weeks | none}}",
  "user": "{{이름 · 역할}}",
  "current_way": ["{{1단계}}", "{{2단계}}", "{{3단계}}"],
  "frequency_per_month": 0,
  "minutes_per_run": 0,
  "wait": "{{none | 건당 N일 · 그동안 못 하는 일}}",
  "why_chain": ["{{증상}}", "{{왜1}}", "{{왜2}}", "{{왜3}}", "{{원인}}"],
  "failed_attempts": [
    {"tried": "{{시도한 것}}", "result": "failed", "why": "{{왜 안 됐나}}"}
  ],
  "unpassed": []
}
```

펜스의 `deadline`과 `wait`는 없을 때 `none`이라고 적는다(식별자처럼 번역하지 않는다).
`failed_attempts`는 시도할 것이 없었으면 문자열 `"not-applicable"`을 적는다.
`unpassed`에는 사용자가 넘어가자고 해서 못 채운 게이트 이름(펜스의 키 이름)을 적는다. 검증기는 그 항목을
`warn`으로 표시하고, interview는 그것을 사실이 아니라 가정으로 옮긴다.
