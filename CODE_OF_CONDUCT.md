# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of
conduct. The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>; it applies
in every project space: issues, pull requests, Discussions, and any other
channel where someone represents the project.

## Reporting

To report behaviour that breaks the code of conduct, contact the maintainers
privately through GitHub — message a maintainer listed on the repository, or,
where the report concerns something that should not be public, use the
repository's private reporting form (**Security** tab → **Report a
vulnerability**) and say in the title that it is a conduct report. Please do
not open a public issue for it.

Reports are read by the maintainers only and handled under the Covenant's
enforcement guidelines (correction, warning, temporary ban, permanent ban).
The privacy and security of the reporter are respected.
