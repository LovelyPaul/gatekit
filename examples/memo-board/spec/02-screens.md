## 화면별 상태

### S1 — 메모 보드

위에서 아래로: 제목 `<h1>메모 보드</h1>`, 개수 줄 `메모 N개` (`data-testid="note-count"`),
입력창 (`data-testid="note-input"`, placeholder "메모를 입력하세요") + "추가" 버튼
(`data-testid="add-note"`), 메모 목록 `<ul data-testid="note-list">` 안의 항목
`<li data-testid="note-item">` — 항목마다 글(`data-testid="note-text"`)과 "삭제" 버튼
(`data-testid="delete-note"`).

| 상태 | 화면에 보이는 것 | 근거 |
|---|---|---|
| 정상 | 메모 항목들이 추가한 순서대로 보이고 개수 줄이 "메모 N개" | 인터뷰 |
| 비어 있음 | 목록 자리에 "메모가 없습니다" (`data-testid="empty-state"`), 개수 줄은 "메모 0개" | 가정 1 |
| 오류 | localStorage를 읽을 수 없거나 JSON이 깨졌으면 빈 목록으로 시작하고 "저장된 메모를 읽지 못했습니다" (`data-testid="error-state"`) 를 보여 준다 | 가정 1 |
| 로딩 | 로딩 상태 없음 — localStorage는 동기라 첫 렌더에 바로 보인다 | 가정 1 |

- 다크 모드가 없다.
